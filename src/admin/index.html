Admin portfolio

Masukkan GitHub token untuk repo portfolio-fauzi. Token hanya disimpan di browser ini.

Cara membuat token
  1. Buka GitHub → Fine-grained token.
  2. Repository access: Only select repositories → portfolio-fauzi.
  3. Permissions → Repository: Contents: Read and write dan Actions: Read-only.
  4. Generate, salin, lalu tempel di sini.
